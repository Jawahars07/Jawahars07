### 🚀 The flagship

- **[adopt](https://github.com/Jawahars07/adopt)** — **AI stack control plane.** Most companies now run Copilot *and* ChatGPT *and* Claude *and* Gemini, with nobody saying which does what. Adopt routes a task to the right tool in the stack you already pay for, learns from what gets abandoned, and shows which tools aren't earning their seats.

  The verdict no single-vendor dashboard can produce: *"Copilot holds 18% adoption for document work, Claude holds 92% — you already pay for both, so this is a routing change, not a purchase."*
